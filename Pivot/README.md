# Sales & Outlet Analysis | SQL

## Project Overview

This project focuses on **sales and outlet performance analysis using SQL**.

The analysis uses an outlet and product-level dataset to investigate sales performance across:

* Outlet types
* Outlet identifiers
* Item types
* Product categories
* Fat-content classifications

The project demonstrates how SQL aggregation techniques can replicate the type of analysis commonly performed using pivot tables in spreadsheet applications and business intelligence tools.

The primary SQL techniques demonstrated include:

* `GROUP BY`
* `ORDER BY`
* `WHERE`
* `HAVING`
* `COUNT()`
* `SUM()`
* `ROUND()`
* Multi-column grouping

---

# Business Objective

The objective is to use SQL to analyze sales performance across different outlet and product dimensions.

The analysis aims to help management:

* Identify the most common outlet types.
* Compare sales performance across outlets.
* Determine which product categories generate the highest sales.
* Compare item performance across outlet types.
* Filter product sales based on fat-content classifications.
* Support outlet-performance evaluation.
* Identify potential sales opportunities.

# Dataset Overview

The dataset contains product and outlet information.

| Field               | Description                             |
| ------------------- | --------------------------------------- |
| `outlet_type`       | Type/category of retail outlet          |

# Analysis 1 — Outlet Types and Counts

The project calculates the number of records associated with each outlet type.

```sql
SELECT outlet_type,
       COUNT(item_outlet_sales) AS total_counts
FROM pivot
GROUP BY outlet_type
ORDER BY total_counts DESC;
```

### Business Question

> Which outlet types have the highest number of sales records?

This provides an overview of the distribution of sales activity across outlet categories.

---

# Analysis 2 — Total Sales by Outlet

The project calculates total sales for each individual outlet.

```sql
SELECT outlet_identifier,
       ROUND(SUM(item_outlet_sales), 0) AS total_sales
FROM pivot
GROUP BY outlet_identifier
ORDER BY total_sales DESC;
```

### Business Question

> Which outlets generate the highest total sales?

This analysis can support:

* Outlet benchmarking
* Performance ranking
* Resource allocation
* Store-management decisions
* Sales-target setting

---

# Analysis 3 — Sales by Item Type and Outlet Type

The project combines two dimensions:

* Item type
* Outlet type

```sql
SELECT item_type,
       outlet_type,
       ROUND(SUM(item_outlet_sales), 0) AS total_sales
FROM pivot
GROUP BY item_type,
         outlet_type
ORDER BY total_sales DESC;
```

This is equivalent to creating a multi-dimensional pivot table.

### Business Value

It allows management to understand whether specific product categories perform better in particular outlet formats.

This can support:

* Product placement
* Inventory planning
* Outlet-specific assortment
* Promotional planning

---

# Analysis 4 — Filtering Out Low-Fat Products

The project filters the analysis to exclude products classified as Low Fat.

```sql
SELECT item_type,
       outlet_type,
       ROUND(SUM(item_outlet_sales), 0) AS total_sales
FROM pivot
WHERE NOT item_fat_content = "Low Fat"
GROUP BY item_type,
         outlet_type;
```

This demonstrates how SQL can be used to create a more focused analysis based on product characteristics.
